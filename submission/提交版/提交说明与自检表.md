## 四、一键验收（提交前跑一遍）

```bash
cd D:/industrial_evolution
./.venv/Scripts/python.exe -m pytest -q
./.venv/Scripts/python.exe -m ruff check src tests
./.venv/Scripts/python.exe -m ruff format --check src tests
./.venv/Scripts/python.exe "submission/提交版/实验记录/离线复核包/复算.py"
cd submission/提交版 && sha256sum -c SHA256SUMS.txt
```

**任何文件改动后**必须重跑打包与校验和锁定：

```bash
cd D:/industrial_evolution
./.venv/Scripts/python.exe "submission/提交版/打包源码.py"
./.venv/Scripts/python.exe -c "
import hashlib
from pathlib import Path
root = Path('submission/提交版').resolve()
rows = []
for p in sorted(root.rglob('*')):
    if not p.is_file() or p.name == 'SHA256SUMS.txt': continue
    h = hashlib.sha256()
    with p.open('rb') as f:
        for b in iter(lambda: f.read(1024*1024), b''): h.update(b)
    rows.append(f'{h.hexdigest()}  {p.relative_to(root).as_posix()}')
(root/'SHA256SUMS.txt').write_bytes(('\n'.join(rows)+'\n').encode('utf-8'))
print('listed', len(rows))
"
```
