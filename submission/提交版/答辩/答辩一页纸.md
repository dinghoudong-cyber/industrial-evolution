# 答辩一页纸 · 工业模型自进化框架（提交版）

**一句话**：我们做的是一套**无人干预的受控自进化 Harness**——不是「每窗都重训」，而是让监测、诊断、实验、门控、上线/拒绝/回滚形成闭环，并把每一轮决策完整留痕。

## 我们真正立住的四件事

1. **闭环不是流程图**：18 窗口合成流 6 次候选、4 次上线、2 次被否定的假设；回滚会连同特征/性能/诊断/策略四类状态快照一起恢复。
2. **抗过拟合有硬证据**：候选训练数据与历史守护集严格隔离并带断言；扩展性实验中候选被拒 29 次、真实触发回滚 4 次，负结果全部保留。
3. **实验记录可复算**：158 条事件、6 条完整「读历史→假设→实验→决策」链、逐批 `decisions.jsonl` 上线/不上线判断；离线复核包一键复算，不依赖云端链接。
4. **资源行为可扩展**：10 场景 × 2 组验证，样本量放大 5.1 倍，墙钟只增 1.9 倍，内存稳定约 170 MiB，模型 < 1.1 MiB；大规模场景累计 10,200 标签，全部窗口完成评估。

## 诚实边界（评委可直接查）

- **阶段边界**：Qwen3.8 27B / 4B 与 PyTRiO 在企业赛阶段才提供，LLM 调用 0 次、Token 0；正式比赛数据与 SDK 入口尚未下发，B 包批次握手与最终 checkpoint 按官方协议导出属企业赛工作。
- **当前闭环与官方格式尚未打通**：闭环产出 sklearn `joblib`，官方协议要 `checkpoint.npz + training.json + history.jsonl`；`run-official` 仍按 CSV 假设。本版已交付 6 条完整决策链（离线复核包）与三份官方格式 CPU 训练报告（不含权重）作为工程证据。
- **不宣称平台成绩**：早期自建真实数据流上为负结果；官方公开 A 包续训 Macro-F1 0.714030 → 0.716641 是公开 validation 上的小幅正增益，标 `official_scoring_ready=false`。「最终不低于官方静态基线」须由正式评测判定。
- **唯一未达标必需材料**：SwanLab 项目当前非公开，需设公开并完成匿名访问验收。
