## 复现边界（重要）

`Dockerfile` 的两处 `pip install` 需要联网，评测机无外网，**不能从源码 `docker build` 重建**；复现路径是 `docker load -i <镜像归档>` 后按《镜像与启动说明》的 `--network none --memory 8g --cpus 4` 契约运行。源码归档用于审阅与审计。

`requirements-extras.txt` 对 openai / swanlab 使用版本区间，重建镜像不保证字节级一致（镜像内为 OpenAI SDK 3.49.0 / SwanLab 0.10.5，本机开发为 3.41.0 / 0.10.4）。镜像归档是冻结产物，源码身份以本文件的 SHA-256 为准。

完整性校验：在 `submission/校赛初版/` 下执行 `sha256sum -c SHA256SUMS.txt`（标准格式，实测 30/30 通过）。平台导入与运行契约仍待校赛侧验证。
