## 2. 整改步骤（由账号持有人操作，本仓库无法代为完成）

1. 登录 swanlab.cn，进入 `industrial_evolution` 项目 → 项目设置 → 可见性 / Visibility → 改为 **公开（Public）**。注意 `1649435028` 是个人数字工作空间；若赛方要求组织空间，需在项目设置里迁移或新建公开组织空间，并同步更新 `configs/tuned.yaml` 的 `swanlab_workspace`。
2. 三条 A/B/C 记录当前只是**静态 baseline**，不是迭代过程。在联网开发机把**闭环迭代 run** 同步上云：
   ```powershell
   # 先确认本地完整记录存在（离线复核包即其副本）
   ./\.venv/Scripts/python.exe "submission\校赛初版\实验记录\离线复核包\复算.py"

   # 用 online 模式跑一次完整闭环，或用 swanlab sync 补传已有 offline 产物
   $env:SWANLAB_API_KEY = "<通过平台安全渠道取得，不要写进任何文件>"
   ./\.venv/Scripts/python.exe -m industrial_evolution.cli demo --config configs\tuned.yaml --swanlab --swanlab-mode online
   ```
   同步后确认云端 run 里能看到：曲线（每窗口得分/漂移/预算）、判断链（观察→诊断→决策→预期→结果→判定）、产物（`summary.json`、`metrics.csv`、`events.jsonl`、`decisions.jsonl`、注册表）。
3. 把云端 run 链接逐条写入《实验记录链接》，并标注哪一条是**闭环迭代**、哪几条是**静态基线**，不再混用。
