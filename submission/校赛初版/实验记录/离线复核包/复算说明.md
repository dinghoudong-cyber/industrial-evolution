## 3. 复算命令

本包自带可直接运行的复算脚本，自动选择包内最后一个 run 目录，不需要网络、不读取权重、不修改文件：

```powershell
.\.venv\Scripts\python.exe "submission\校赛初版\实验记录\离线复核包\复算.py"
```

脚本会打印事件分布、六条决策链、负结果条数、逐批判断统计、摘要指标、版本链、源码 SHA-256 与权重状态；全部一致时返回退出码 0。

`summary.json` 中的 `source_sha256`、`config_sha256` 可与当前源码、配置文件复算比对；`metrics.csv` 的 `score` 列与 `events.jsonl` 的 `drift_diagnosis` 事件可逐窗口对齐。

## 4. 与官方评分的边界（必须保留）

- 本 run 使用**合成漂移流**与项目自建 sklearn 模型，主指标为 `balanced_accuracy`；**不是**官方 A/B/C 数据包、不是官方主指标（Macro-F1 / RMSE）、不是平台成绩。
- 平均值 0.676200 vs 自建静态对照组 0.614526 只说明工程闭环在合成流上的行为，不能推导到官方隐藏数据。
- 末次上线 v004 的 holdout 得分 0.660055 低于 v003 最后窗口 0.699060，**没有已验证收益**，该负结果原样保留在 `summary.json` 与 `final_deployment_summary` 事件中。
- `vs_official_baseline=null`：本配置未填官方基线分，不与官方口径比较；口径对齐方式见 `configs/official.yaml`。
- 本包不替代 SwanLab 公开链接；两者关系见《实验记录链接》与《SwanLab记录公开性整改说明》。
