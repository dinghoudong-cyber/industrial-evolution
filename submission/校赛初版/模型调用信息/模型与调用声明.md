# 模型与 Harness 调用信息（校赛提交版）

## 1. 阶段边界（为什么不接 Qwen）

赛题规则说明：**Qwen3.8 27B / Qwen3.5 4B 模型服务与 PyTRiO 后训练能力在进入企业赛阶段后才提供**（同时发放 500 元 PyArrow 平台代金券）。当前是**校赛**阶段，因此本方案：

- 不下载、不打包、不分发任何平台模型权重；
- 不填写真实 served model ID（配置模板中的 `QWEN3_8_MODEL_ID` 是**占位符**，不是服务清单里的 ID）；
- 不估填任何调用次数、Token、延迟或费用。

| 角色 | 校赛阶段状态 |
|---|---|
| Harness | 本项目自研 `EvolutionOrchestrator`（`src/industrial_evolution/orchestrator.py`），规则门控驱动闭环 |
| 策略大模型 | **未启用**；`configs/*.yaml` 全部 `llm.enabled: false`，模型 ID 为占位符 |
| 被训工业模型 | 项目自建 sklearn HistGradientBoosting（CPU，无 GPU 依赖） |
| 官方任务模型 | 仅加载 A/B/C 公开包随附 `checkpoint.npz` 做静态评估，不续训（`epochs=0`） |
| PyTRiO 后训练 | 未使用，无后训练模型 ID |
| DeepSeek 模型 API | 仅 `configs/deepseek-dev.yaml` 存在开发调试端点声明，正式 Harness 不使用，未发生调用 |

## 2. 命名澄清（避免评委误判违规外联）

早期材料把运行框架称为「DeepSeek Harness」，同时项目里又存在「DeepSeek 仅开发调试、不得作为正式模型」的表述，两者容易被读成「调用了被禁止的外部模型 API」。**提交版统一改称「本项目自研 Harness」**，并明确：

- 「DeepSeek Harness」当时只是团队给运行框架起的名字，不表示底层使用 DeepSeek 模型，也不表示已接入某个具体商业产品；
- 代码中 `configs/deepseek-dev.yaml` 与 `llm/deepseek_provider.py` 属联网开发调试通道，**不在正式镜像的运行路径上**（镜像默认 `configs/tuned.yaml`，LLM 关闭）；
- 正式 Harness 未来应接入的是平台允许的 Qwen 模型服务，且只能通过 `openai_compatible` provider 指向平台提供的端点。

## 3. 当前实际调用情况

2026-11-12 的全部提交证据中：

- **LLM / Qwen 调用次数：0；LLM Token：0；PyTRiO 后训练：0 次。**
- A/B/C 公开包评估：加载包内任务模型 checkpoint，对公开 validation 计算静态指标；这是**任务模型的前向预测**，不是驱动 Agent 的对话模型调用。
- 合成流闭环与 10 场景扩展性验证：策略决策全部由 `RuleBasedPolicy` 完成，未请求任何大模型。
- 断网容器烟测：`llm_calls=0`、`llm_fallbacks=0`，18 窗口全部完成。

0 次调用不是「没有模型预测」，而是校赛阶段没有可用的平台驱动模型服务；不把 0 写成已发生，也不把任务模型预测冒充 Harness 决策。

## 4. 已就绪但默认关闭的接入能力

代码侧已具备、待企业赛拿到服务信息后启用：

- `LLMConfig.provider` 支持 `openai_compatible`（本地/内网 OpenAI 兼容端点）与 `deepseek`（仅开发调试）；
- 端点安全校验：公网强制 https、禁止 URL 内嵌账号/查询串、`api_key_env` 必须是大写且以 `API_KEY`/`TOKEN` 结尾、`allowed_hosts` 白名单、私网判定；
- 运行时容错：端点不支持 `response_format` 时降级为提示词约束并重试一次；超时/非法 JSON/低置信度回退规则策略，事件流记 `llm_fallback`；
- `llm-smoke-test`、`env-check` 可做接入后自检，验收标准是 `llm_calls>0`、`llm_fallbacks=0`。

> 说明：**即使启用，当前 LLM 也只是「规则已决定重训后的受限否决器」**（动作白名单仅 `no_update` / `retrain_with_replay`），监测、诊断、评估、上线、回滚仍由规则完成。把它扩展成能主动提出假设、调整阈值的智能体，是企业赛阶段的技术创新方向，不在此处预先宣称。
