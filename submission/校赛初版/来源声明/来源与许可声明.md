## 2. 按阶段尚未发生（校赛阶段，不作许可声明）

- **Qwen3.8 27B / 4B**：赛题规则明确该模型服务在企业赛阶段才提供。校赛阶段未下载权重、未打包权重、未发生调用；模型调用记录为 0 次、Token 0。企业赛拿到平台 served model ID 后，按《企业赛平台对接清单》补充模型来源、版本、许可与调用记录。
- **PyTRiO 后训练**：未使用，无后训练模型 ID、无产物。
- **DeepSeek 模型 API**：仅 `configs/deepseek-dev.yaml` 中存在开发调试端点声明，正式 Harness 不使用，未发生调用。
- **Harness 命名澄清**：早期材料中「DeepSeek Harness」指团队选定的**运行/驱动框架名称**，不表示底层调用 DeepSeek 模型，也不表示已接入某个具体商业产品。为避免误解，提交版统一称为「本项目自研 Harness（`EvolutionOrchestrator`）」；企业赛如需接入平台指定框架，再按官方名称补充。
