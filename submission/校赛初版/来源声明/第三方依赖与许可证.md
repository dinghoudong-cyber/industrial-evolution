# 第三方依赖与许可证清单（校赛提交）

本清单由本机已安装发行包的 PEP 658 / PEP 639 元数据自动读取（命令见文末），**不是人工猜测**。许可证表达式取自 `License-Expression` 字段，缺失时取 `Classifier: License ::` 或发行包随附 LICENSE 文本。完整许可正文位于各包 `*.dist-info/licenses/` 或发行包根目录，可随源码归档一起核对。

## 3. 基础镜像与系统组件

- 基础镜像：`python:3.13.7-slim-bookworm`（Python 软件基金会许可证 + Debian 系统组件各自的许可），随 `Dockerfile` 声明，不随本作品重新分发。
- 本作品**未**引入 torch / transformers / vLLM / Embedding 模型 / CUDA 等 GPU 或大模型依赖；`requirements.lock`、`requirements-extras.txt`、`pyproject.toml` 均无相关条目，镜像层扫描也未发现大体量机器学习库。符合赛题「运行环境不含 GPU、不建议打包 Embedding」的约束。

## 4. 数据、基线模型与自建内容

| 内容 | 来源与许可边界 | 是否随包分发 |
|---|---|---|

## 6. 复算命令

```powershell
.\.venv\Scripts\python.exe -c "from importlib import metadata as m; import sys; [print(n, m.version(n), m.metadata(n).get('License-Expression') or [c for c in (m.metadata(n).get_all('Classifier') or []) if c.startswith('License')]) for n in ['numpy','pandas','scipy','scikit-learn','joblib','pydantic','PyYAML','pytest','ruff','openai','swanlab']]"
```
