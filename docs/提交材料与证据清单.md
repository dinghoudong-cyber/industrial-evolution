# 参赛提交材料与证据清单（2026-11-14 校赛提交版）

本清单按赛题通知整理。平台使用不同于开发参考包的正式数据进行测评并负责评分；本地公开数据结果只说明开发阶段的兼容性与实验观察，不代表正式成绩。不得获取隐藏测试标签或把本地模拟结果写成平台结果。

**总评**：按校赛阶段口径，七类必需材料中 6 类已齐；SwanLab 项目已于 **2026-11-14** 复核为 `PUBLIC`，匿名可见 9 个实验，但闭环迭代 run 尚未同步、匿名验收截图待补，因此实验记录交付仍未闭合。合规硬伤（权重入包、校验和格式、许可证、运行契约）已清理；基础门槛（Harness、≥3 次迭代、≤2 GiB、无权重、无外网四核 8 GiB 可运行）已闭合。官方 JSONL 包接入闭环与最终 checkpoint 按官方协议导出**属企业赛工作**——正式比赛数据与平台 SDK 入口尚未下发，校赛阶段不作为缺陷申报。提交门面见 `submission/校赛初版/校赛提交说明与自检表.md`。

## 三、当前公开开发结果边界

`docs/官方CPU包本地验证.md` 记录 A/B/C 包内 checkpoint 在公开 validation 上的静态基线。三包随附训练报告均标记为开发参考而非正式评分就绪。该结果不是隐藏数据测评，不包含正式漂移流阶段的平均增益、最差阶段、恢复速度或全队资源排名。
