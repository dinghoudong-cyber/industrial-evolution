# 官方数据包接入说明

数据包发布前，结构是未知的。因此接入层不写死目录约定，而是按三级优先级解析：

```text
命令行参数  >  数据包清单（manifest）  >  按常见命名推断
```

任何一级都无法确定时，程序**启动即报错**，并把「找过哪些文件名、缺哪一列」写进错误信息，
不会带着错误的结构跑完一整轮再产出无效结果。

## 1. 首选：在包根目录放一份清单

`manifest.json`（也支持 `manifest.yaml`、`pack.json`、`pack.yaml`）：

```json
{
  "target_column": "label",
  "id_column": "row_id",
  "timestamp_column": "ts",
  "initial_file": "initial.csv",
  "stream_file": "stream.csv",
  "initial_size": 2000,
  "window_size": 500,
  "task_type": "classification",
  "drop_columns": ["device_id", "operator_note"]
}
```

| 字段 | 必填 | 说明 | 别名 |
|---|---|---|---|
| `target_column` | 是 | 标签列名 | `label`、`target` |
| `initial_file` | 否 | 带标签的冷启动集 | `train_file` |
| `stream_file` | 否 | 按时间顺序评测的流文件 | `test_file` |
| `initial_size` | 否 | 冷启动集取前多少行 | — |
| `window_size` | 否 | 每个窗口多少行 | — |
| `id_column` | 否 | 样本ID，用于跨窗口去重与守护集隔离 | `id`、`sample_id` |
| `timestamp_column` | 否 | 时间列，仅声明排除，不参与训练 | `timestamp` |
| `drop_columns` | 否 | 需要排除的非数值列 | `ignore_columns` |
| `task_type` | 否 | `classification` / `regression` | — |

## 2. 其次：按命名推断

没有清单时，会依次尝试：

- 初始集：`initial.csv` → `train.csv` → `initial_train.csv` → `warmup.csv`
- 评测流：`stream.csv` → `test.csv` → `eval.csv` → `holdout.csv` → `stream_test.csv`

推断不出来时通常还需要 `--target`（标签列名），`initial_size` / `window_size` 缺失时先用
`configs/official.yaml` 里 `stream` 段的值兜底。

## 3. 最后：命令行覆盖

```powershell
python -m industrial_evolution.cli run-official `
  --pack D:\官方数据包 `
  --target label `
  --initial-file warmup.csv `
  --stream-file hidden_test.csv `
  --id-column row_id `
  --initial-size 2000 `
  --window-size 500 `
  --drop-column device_id `
  --print-spec          # 只打印解析结果，不跑
  --config configs\official.yaml
```

`--print-spec` 会输出实际生效的文件、列、窗口数、被忽略的行数，建议拿到数据包后**先跑这一步**，
确认解析没偏差再跑完整流程。

## 4. 接入层会替你挡住的几类问题

| 情况 | 行为 |
|---|---|
| 目标列缺失 | 报错并列出实际列名 |
| 特征列非数值 | 报错并提示用 `drop_columns` 排除 |
| 特征含无穷值 / 标签缺失 | 报错并指出文件名与列名 |
| 初始集与评测流样本ID重复 | 报错（否则历史守护集会与训练集重叠，运行中途才炸） |
| 评测流行数不足一个窗口 | 启动前报错，不会跑出空结果 |
| 初始集行数少于 `initial_size` | 报错，不会静默截断 |
| 初始集行数多于 `initial_size` | 只用前 `initial_size` 行，`initial_rows_ignored` 记录被忽略的行数 |

## 5. 尚未支持

- **标签延迟**：数据包里若标签要延迟若干窗口才可见，当前仍需先做一次合并再接入（`StreamSource`
  接口还需要增加「窗口未标注」的状态）。
- **官方评测脚本直接对接**：现在按文件接入，不调用官方 evaluator；若官方要求用其脚本输出指标，
  需要在 `data/official.py` 外再包一层适配。
