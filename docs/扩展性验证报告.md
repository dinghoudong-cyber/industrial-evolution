# 扩展性验证报告

**日期**：2026-11-12　**脚本**：`tools/扩展性验证实验.py`　**原始证据**：`runs/scalability/实验结果.json`、`实验结果.csv` 与 20 个独立 run 目录

> 本实验使用合成漂移流与项目自建 sklearn 模型，主指标 `balanced_accuracy`；静态对照为同一框架关闭更新的对照组。结果用于说明框架的扩展性与资源行为，官方 A/B/C 公开包证据另见《实验记录/》。

## 1. 实验设计

以 `configs/tuned.yaml` 为基准，固定随机种子 42，逐项改变四个维度，共 10 个场景；每个场景跑「自进化」与「静态对照」两次，共 20 次独立运行：

| 维度 | 取值 |
|---|---|
| 数据规模 | 每窗 100 / 200 / 400 样本，14 / 18 / 24 窗口（总样本 2,000 / 4,200 / 10,200） |
| 标签噪声 | 0.02 / 0.08 / 0.20 |
| 漂移时机 | 渐进/突发起点 3/8（早）、6/12（基准）、10/15（晚）、12/18（长稳定期） |
| 特征维度 | 4 / 8 / 16 |

每次运行记录：平均得分、末窗得分、尝试/上线/拒绝/回滚次数、墙钟、训练秒数、标签数、进程工作集、模型体积。

## 2. 结果

| 场景 | 自进化 mean | 静态 mean | 平均增益 | 迭代/上线/拒绝/回滚 | 墙钟 s | 标签数 |
|---|---:|---:|---:|---|---:|---:|
| 基准（200×18, 8 维） | 0.6762 | 0.6145 | **+0.0617** | 6/4/2/0 | 1.78 | 4,200 |
| 小规模（100×14） | 0.6675 | 0.6361 | +0.0314 | 6/4/2/0 | 1.48 | 2,000 |
| 大规模（400×24） | 0.6856 | 0.6055 | **+0.0801** | 8/3/5/0 | 2.87 | 10,200 |
| 低标签噪声 0.02 | 0.6992 | 0.6608 | +0.0384 | 5/1/4/0 | 1.52 | 4,200 |
| 高标签噪声 0.20 | 0.5748 | 0.5582 | +0.0166 | 4/2/2/**1** | 1.45 | 4,200 |
| 早漂移 3/8 | 0.5800 | 0.5800 | **0.0000** | 6/**0**/6/0 | 1.62 | 4,200 |
| 晚漂移 10/15 | 0.6742 | 0.6604 | +0.0138 | 3/3/0/**1** | 1.26 | 4,200 |

汇总：多数场景取得正增益，平均 +0.041694；迭代次数 3–8，全部满足赛题「至少三次」；0 失败窗口，全部窗口完成评估；墙钟 1.26–2.87 s，训练耗时 0.48–1.75 s，进程工作集 170.24–173.43 MiB，模型体积 0.27–1.09 MiB。

## 3. 可写进答辩的结论

1. **规模扩展性**：总样本从 2,000 增至 10,200（5.1 倍），墙钟仅从 1.48 s 增至 2.87 s（1.9 倍），工作集稳定在约 170 MiB，没有随数据流线性膨胀。回放缓冲有容量上限、每次上线只保留状态快照，是主要原因。
2. **标签按 `count_only` 模式记账**：大规模场景累计 10,200 个标签，全部窗口完成评估；标签预算与按批次提供标签的运行方式一致。
3. **抗过拟合证据**：20 次运行中候选被拒绝 29 次、触发回滚 4 次，均完整保留在 `events.jsonl` / `decisions.jsonl`。回滚集中出现在**高噪声、晚漂移、高维度、长稳定期**四类场景，可作为回滚链路的实测证据。
4. **稳定性边界与守护集行为**：
   - **早漂移 3/8**：候选未通过守护集校验时保持原版本，系统表现稳定持平；门控优先保证既有表现不回退。
   - **高标签噪声 0.20**：仍保持正增益 +0.0166，并触发 1 次回滚；守护集约束在噪声升高时优先保证稳定性。
   - **长稳定期**：收益主要集中在漂移之后的窗口，稳定期内保持已验证版本。
5. **资源效率**：四核 8 GiB 无 GPU 环境下，单次完整闭环墙钟 < 3 s、训练累计 < 2 s、内存约 170 MiB、模型 < 1.1 MiB，远低于约束，可把余量留给平台模型调用与正式数据流。

## 4. 验证范围与后续工作

- 本实验以合成漂移流为主，主指标为 `balanced_accuracy`；官方 A/B/C 公开包的静态基线与 CPU 续训证据另见《实验记录/》。
- 静态对照为同一框架关闭更新的对照组；`vs_official_baseline` 仅在口径一致时给出增益，否则记为 `null`。
- 工作集为单进程连续运行读数，用于观察随规模的资源变化。
- 跨领域真实数据（气体 / 轴承 / 发动机）的闭环对照与按批次协议对接列入后续工作。
- 本实验用于说明框架扩展性与资源行为；官方公开包证据与自研闭环证据分列呈现。
